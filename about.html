About The Project

CoursePath is a Course Prerequisite Checker developed using the concept of Directed Graphs.

Project Objective

The objective is to help students understand course dependencies and determine whether they are eligible to register for a particular course.

Data Structure Used

The system uses a Directed Graph where courses are represented as vertices and prerequisite relationships are represented as directed edges.

Algorithms Used

Depth First Search (DFS) is used to determine the prerequisite path of a selected course.

Technologies

HTML, CSS, JavaScript and Directed Graph algorithms.
